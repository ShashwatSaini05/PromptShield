# PromptShield-App\n\nApplication layer for PromptShield-ML: a FastAPI backend,\nReact frontend, JWT auth, and SQLite database wrapping the trained\nprompt-injection classifier.\n\n## Quick Start\n\n### Backend\n\n`ash\ncd backend\npython -m venv venv\nvenv\\Scripts\\activate   # Windows\npip install -r requirements.txt\nuvicorn app.main:app --reload\n`\n\nAPI at http://localhost:8000 - visit /docs for Swagger UI.\n\n### Frontend\n\n`ash\ncd frontend\nnpm install\nnpm run dev\n`\n\nOpen http://localhost:5173\n\n## API Endpoints\n\n| Method | Path | Auth | Description |\n|--------|------|------|-------------|\n| POST | /auth/signup | None | Create account |\n| POST | /auth/login | None | Get JWT |\n| GET | /auth/me | Required | Current user |\n| POST | /predict | Optional | Classify prompt |\n| POST | /predict/batch | Optional | Classify multiple |\n| GET | /history | Required | User history (paginated) |\n| GET | /health | None | Service health |\n\n## Database\n\nSQLAlchemy + SQLite with create_all() at startup.\nSwap to PostgreSQL by changing DATABASE_URL only.\n\nTables: users (id, email, password_hash, created_at),\nprediction_logs (id, user_id nullable, prompt_text, predicted_label, confidence, created_at)\n\n## Auth Details\n\n- bcrypt cost factor 12\n- JWT HS256, 30min expiry\n- Generic login error messages (never reveals if email exists)\n- Token stored in localStorage (tradeoff: simpler but XSS-vulnerable;\n  acceptable for internal tools, use httpOnly cookies for public apps)\n\n## Rate Limiting\n\n60 req/min per IP on /predict (configurable). Returns 429 when exceeded.\n\n## Tests\n\n`ash\ncd backend && pytest tests/ -v\n`\n\n## Security Limitations (from Stage 1)\n\nThis is a statistical classifier - not a guarantee of safety.\nFalse positives/negatives possible. Synthetic training data.\nBorderline confidence (0.4-0.6): route to human review.\nRaw text only - cannot detect indirect injection via RAG, tools, files.\nUse as ONE layer of defense, not a sole safeguard.
